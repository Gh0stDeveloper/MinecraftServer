# Lobby Behavior Pack

## NPC esperados

Crea cuatro NPC en el lobby y asigna exactamente estos `nameTag`:

- `Survival`
- `PvP`
- `BedWars`
- `SkyWars`

El script detecta la interacción por nombre y transfiere al jugador.

También permite abrir el selector con una brújula o escribiendo `!menu`.

Antes de instalar, ejecuta `scripts/render-lobby-config.sh` para fijar la IP/dominio público.
