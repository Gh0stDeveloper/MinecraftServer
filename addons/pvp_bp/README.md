# PVP Behavior Pack

Framework inicial de cola y estados para Solo, Duo y Escuadra.

- Brújula o `!play` abre el menú.
- Evita que un jugador esté en dos colas simultáneas.
- Limpia desconectados.
- Cuando se alcanza el mínimo, reserva el grupo para iniciar partida.

Pendiente de la siguiente fase: ArenaManager, spawns, equipos, reglas específicas, reset y persistencia de estadísticas.
